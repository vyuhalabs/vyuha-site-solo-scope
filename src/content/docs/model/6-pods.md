---
title: Pods
description: A pod is the set of roles a stage needs, hired when the stage starts.
order: 6
---

A **pod** is the set of roles a stage needs. When a stage starts, its pod hires those roles: a planner agent for planning, builder agents for the build, a reviewer agent and a QA agent to verify, and a person wherever the stage needs one.

When the stage ends, so does its pod. The next stage hires the roles it needs.
