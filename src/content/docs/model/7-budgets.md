Each project has a **budget**, with **spending thresholds**. Below a threshold, agents spend within their limits. Spend above it is a decision for a person, and it waits in the Inbox like any other approval.

Every run shows what it spent against its budget. And when you need everything to stop, the **stop button** halts every run within two seconds.
