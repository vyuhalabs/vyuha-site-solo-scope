Everything an agent does leaves **evidence**: the commands it ran and their exit codes, the tests, screenshots and the pull request.

A person or a reviewer agent checks the evidence against the issue before the work counts as done. Every action, by an agent or a person, is kept in the **audit trail**: who did what, when and why.
